Connect to GitHub

Create one at github.com → Settings → Developer settings → Personal access tokens (fine-grained, with "Contents: Read and write" permission on this repo only). This token is stored only in your browser's local storage on this device — it is never sent anywhere except directly to GitHub's own API. Click Save to lock it in place, and Edit whenever you need to change it.

Your apps are always safe: the token here is only a temporary key that lets this admin panel talk to GitHub — it has no effect on your saved apps. If a token expires or is replaced, all 74+ apps already saved in apps.json stay exactly as they are. Connecting with a new token for the same repository simply continues managing that same, unchanged data.
